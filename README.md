**Projeto Fintech | FIAP 2026**
**Thiago Linares de Abreu | RM: rm569007**

---

## Sobre o projeto

Tela de Dashboard do sistema **Seu Futuro Agora**, uma fintech voltada para planejamento de aposentadoria para jovens. O dashboard apresenta as principais métricas financeiras do usuário, gráfico de crescimento patrimonial projetado e acompanhamento de metas de poupança.

Esta tela foi desenvolvida com base nas User Stories definidas na Fase 1 e nos wireframes criados na Fase 2 do projeto.

---

## Tecnologias utilizadas

- HTML5
- CSS3 (arquivo separado `style.css`)
- Tailwind CSS (via CDN)

---

## Como abrir o projeto

1. Faça o download ou clone o repositório
2. Abra o arquivo `index.html` diretamente no navegador
3. Não é necessário instalar nada — o Tailwind é carregado via CDN

---

